# Slippery Fairy v2 — by Sylredhel

진폭이 아니라 **신호의 상승/하강 속도(기울기, $dx/dt$) 비대칭**으로 짝수차 배음과 실키한 트랜지언트 라운딩을 만드는 속도 기반 새츄레이터 VST3입니다.

---

## v2 핵심 업그레이드

1. **5단계 안티앨리어싱 오버샘플링 (`OFF / 2x / 4x / 8x / 16x`)**
   - JUCE `filterHalfBandFIREquiripple` (`isMaxQuality = true`) 기반 다단 선형 위상 안티이미징 + 안티앨리어싱 FIR 오버샘플링 뱅크를 미리 할당해 RT 안전하게 실시간 전환합니다.
   - `OFF (1x)`에서도 내부 RK2 서브스텝(`>= 192 kHz` 유효 적분률)을 적용해 소신호 고역 응답을 평탄하고 안정적으로 유지하며, DAW PDC 레이턴시를 자동 갱신합니다.
2. **12종 팩토리 프리셋 + 사용자 XML 저장/불러오기 (`PresetManager.h`)**
   - 마스터링, 보컬, 드럼 버스, 심벌/오버헤드, 어쿠스틱, 신스 리드, 베이스, 피아노, 패럴렐 2차 배음 익사이터까지 12종 내장 프리셋과 `SAVE / LOAD` 기능을 제공합니다.
3. **Sylredhel 스케치북 연필 UI + 물리 연동 미끌미끌 요정 마스코트**
   - `Origami Fairy v2`와 통일된 크림색 스케치북 종이 + 스프링 제본 + 색연필 UI + 하단 1줄 호버 가이드(`GUIDE:`).
   - 우측 상단의 연필 손그림 **미끌미끌 요정**이 웅덩이 위에서 `SLIP` 활동량과 `RISE / FALL ASYM` 극성(`+` 우측 스키드 / `-` 좌측 스키드 / `0%` 젤리 진동)에 실시간 반응하며 균형을 잡습니다.
